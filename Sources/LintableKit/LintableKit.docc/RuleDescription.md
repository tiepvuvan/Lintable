# ``LintableKit/RuleDescription``

Everything Lintable shows about a rule: its ID, name, summary, rationale, category, default severity, option descriptions, examples, and a "How to fix" section. The documentation page is generated from it.

``documentationURL`` is where reports such as SARIF and JSON link the rule. It defaults to the rule's page in Lintable's repository; a custom rule pack passes the address of its own page.
